# NEXUS SHOP bot

## Запуск
1. `pip install -U aiogram pillow pymysql`
2. В `nexus_bot.py` (блок CONFIG) впиши `BOT_TOKEN` и проверь `ADMIN_ID` (число) и `OWNER_USERNAME`
3. `python make_banners.py` — баннеры в images/ (или положи свои)
4. `python nexus_bot.py`

Товары для выдачи после оплаты: `files/project.zip`, `files/mod_v1.zip`
(заменять можно прямо из бота: /admin → «Файлы товаров»).

## Админ-панель (/admin или кнопка «Админ-панель» в меню)
- Статистика, последние заказы
- Рассылка (любое сообщение всем пользователям)
- Пользователь: премиум вкл/выкл, бан/разбан, сброс проб (по ID или @username)
- Цены (рубли/звёзды по каждому товару)
- Настройки: реквизиты, ссылки, юзернейм для звёзд, режим приёма звёзд
- Файлы товаров, эмодзи

## Звёзды
`dm` (по умолчанию): покупателю показывается инструкция отправить подарок на @OWNER_USERNAME
и прислать скриншот — ты подтверждаешь кнопкой, товар выдаётся автоматически.
Telegram не позволяет перевести «голые» звёзды другому человеку, поэтому используются подарки.
`invoice`: обычный счёт в боте (звёзды копятся на балансе бота). Переключается в админ-панели.

## Премиум-эмодзи (нужен Telegram Premium у владельца бота)
Пришли боту премиум-эмодзи → он ответит ID и предложит:
- «В тексты» — этот эмодзи заменится во ВСЕХ сообщениях бота
- «На кнопку» — выбор кнопки из списка
Команды: /emojis, /setemoji ключ ID, /settxt ⚡ ID, /delemoji, /deltxt
ID хранятся в emoji.json, настройки — в settings.json.
